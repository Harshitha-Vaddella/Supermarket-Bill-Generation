# Supermarket Bill Generation System

## Project Overview
A Python-based Supermarket Billing System designed to manage product purchases and generate customer bills.

## Features
- Display available products and prices
- Add products to shopping cart
- Enter product quantities
- Calculate subtotal automatically
- Calculate 12% tax
- Generate detailed customer bills
- Display customer name and purchase date/time
- Handle invalid inputs

## Technologies Used
- Python

## Concepts Used
- Dictionaries
- Functions
- While Loops
- Conditional Statements
- Exception Handling
- Date and Time Module
- String Formatting

## How to Run
1. Install Python.
2. Clone or download this repository.
3. Open the project in VS Code.
4. Run the following command:

```bash
python supermarket_billing_system.py
```
